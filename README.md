## Работа с SPA модулем
### 1. Одноразовая инициализация

Запуск кода при появлении конкретного элемента на странице.

```js
SPA(() => {
  initGallery();
}, { id: 'photo-gallery' });
```

### 2. Динамические элементы (Watch-режим)

Обработка каждого нового элемента в бесконечных лентах или динамических списках.

```js
SPA((node) => {
  // node — это конкретный найденный DOM-элемент
  new Tooltip(node); 
}, { className: 'feed-item', continuous: true });
```

## Параметры

|Параметр|Тип|По умолчанию|Описание|
|---|---|---|---|
|`fn`|`Function`|—|Колбэк. В режиме `continuous` принимает аргумент `node`. Без него вызывается без аргументов.|
|`id`|`string`|`null`|ID целевого элемента (`#id`).|
|`className`|`string`|`null`|CSS-класс целевого элемента (`.class`).|
|`selector`|`string`|`null`|Произвольный селектор. **Приоритет выше**, чем у `id` и `className`.|
|`continuous`|`boolean`|`false`|`true` — постоянный мониторинг DOM. `false` — одноразовый запуск и остановка.|
|`timeout`|`number`|`3000`|Время ожидания элемента в мс (только для `continuous: false`).|

> ⚠️ **Важно:** Указывайте хотя бы один идентификатор (`id`, `className` или `selector`). Если не указать ни одного, функция выполнится немедленно при первой возможности.
